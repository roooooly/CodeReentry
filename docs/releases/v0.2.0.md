# DevHub 0.2.0 Source Beta

DevHub 0.2.0 makes returning to an AI-assisted coding project more complete and more
measurable. It adds bounded OpenCode session discovery, puts explicit session scans in
the recovery flow, records where project-memory summaries came from, and adds repeatable
privacy and performance gates.

## Run this release

This is a **source beta**. No binary is attached because DevHub does not yet have a
Developer ID signed and Apple-notarized public build. Do not install binaries from
unofficial mirrors.

Requirements: macOS 14 or newer and Xcode with Swift 6 support.

```bash
git clone --branch v0.2.0 https://github.com/roooooly/DevHub.git
cd DevHub
./scripts/run-source.sh
```

The script builds into the ignored `build/` directory, verifies the app bundle, and
launches it. DevHub does not scan projects or sessions until the user explicitly asks.

## What changed

- Discover up to 1,000 recent active OpenCode v1.18.19 sessions per validated SQLite
  database using read-only connections, then resume the exact session with `--session`.
- Scan local sessions explicitly from onboarding and the project overview.
- Record session-summary provenance and warn before handing outdated or unverifiable
  context to another tool.
- Bound the global session list to explicit 500-row metadata batches.
- Add a privacy-safe real-use recorder that keeps raw evidence outside the repository.
- Add reproducible small, medium, and 20,000-session Release performance scenarios.

## Verification

The main-branch CI run for this release verifies the committed one-command source build,
the DevHubCore suite, synthetic performance fixtures and summaries, English and
Simplified Chinese app tests, repository privacy boundaries, and the re-entry recorder.

The current 20,000-session formal performance run completes its initial scan in 1.902
seconds against an unchanged 15-second budget, verifies every indexed row, and stays
within all published memory and cycle-growth budgets. Full methods and retained failed
controls are in [`docs/performance-baseline.md`](../performance-baseline.md).

## Known limits

- Public installation remains source-only until Developer ID signing, notarization,
  Gatekeeper verification, and a clean-Mac installation check are complete.
- OpenCode support discovers metadata and resumes the original session; it does not read
  OpenCode message bodies inside DevHub.
- Kimi support is metadata-only and cannot resume an exact session.
- The project-recovery hypothesis still needs ten privacy-safe real re-entry attempts;
  engineering tests are not presented as user evidence.
