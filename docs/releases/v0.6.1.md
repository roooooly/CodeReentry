# CodeReentry 0.6.1 Source Beta

CodeReentry 0.6.1 is a focused evidence-integrity patch for the local recovery loop. It
freezes recovery duration when the developer confirms that context is ready, before the
structured result form opens. Time spent entering a result can no longer inflate the
recorded recovery metric.

## Install the source beta

This remains a **source beta**. No binary is attached because the project does not yet
have a Developer ID signed and Apple-notarized public build. Do not install binaries
from unofficial mirrors.

Requirements: macOS 14 or newer and Xcode with Swift 6 support.

```bash
git clone --branch v0.6.1 https://github.com/roooooly/CodeReentry.git
cd CodeReentry
./scripts/run-source.sh --install
```

To evaluate the complete interface with disposable synthetic data and no access to local
projects or sessions, use `./scripts/run-source.sh --demo` instead.

## Trustworthy local evidence

- Selecting **Record Recovery Result** freezes the measured duration before the form
  opens. Canceling the form preserves the frozen value for a later honest submission;
  discarding the measurement records nothing.
- **Delete All Local Records** requires confirmation and removes only the owner-controlled
  recovery CSV plus an unfinished in-memory timer. Projects, sessions, source files, and
  unrelated application-support data remain untouched.
- A malformed regular CSV remains visible to the management control so it can be removed.
  Symbolic links, directories, and other non-regular targets are rejected.
- Bundle metadata now derives from the project version used by XcodeGen. Release
  verification rejects stale hard-coded Info.plist versions before packaging.

The evidence schema still excludes project identifiers, names, paths, session IDs,
prompts, messages, source content, and free-form notes. CodeReentry has no evidence upload
path. Engineering fixtures are not counted as real-user recovery evidence.

## Verification boundary

The tag is created only after main passes the one-command source build, transactional
source-install tests, all DevHubCore tests, synthetic performance checks, English and
Simplified Chinese app tests, repository privacy audit, and re-entry-recorder tests.

Public binary distribution remains blocked on Developer ID signing, notarization,
Gatekeeper verification, and a clean-Mac installation check.
