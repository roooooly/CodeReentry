# CodeReentry 0.4.0 Source Beta

CodeReentry 0.4.0 adds native Gemini CLI project-session recovery: bounded local
discovery, on-demand conversation viewing, and exact resume using the full session UUID.

## Run this release

This remains a **source beta**. No binary is attached because the project does not yet
have a Developer ID signed and Apple-notarized public build. Do not install binaries
from unofficial mirrors.

Requirements: macOS 14 or newer and Xcode with Swift 6 support.

```bash
git clone --branch v0.4.0 https://github.com/roooooly/CodeReentry.git
cd CodeReentry
./scripts/run-source.sh
```

The command builds and verifies `CodeReentry.app` under the ignored `build/` directory.
The app does not scan projects or sessions until the user explicitly requests it.

## Gemini CLI support

- Discover project-scoped JSONL sessions from Gemini CLI's local storage.
- Resolve project ownership only from the official `.project_root` marker or
  `projects.json` registry; opaque identifiers are not guessed.
- Apply rewind and checkpoint records before displaying current conversation state.
- Keep subagent histories out of the independent, resumable session index.
- Load conversation bodies only on demand with explicit byte, line, message, and
  character limits.
- Resume an exact session with `gemini --resume <full-uuid>` while honoring the saved
  executable and environment.
- Add Gemini CLI once to existing tool catalogs while preserving prior removals and
  respecting any later user deletion.

The implementation contract and pinned upstream sources are recorded in the
[Gemini CLI compatibility note](../gemini-cli-compatibility.md). Tests contain only
synthetic sessions derived from the public schema.

## Verification boundary

The release is tagged only after the main branch passes the one-command source build,
DevHubCore tests, synthetic performance gates, English and Simplified Chinese app tests,
repository privacy audit, and re-entry-recorder tests.

Engineering tests are not presented as real-user evidence. The recovery hypothesis still
requires privacy-safe real attempts, and public binary distribution remains blocked on
Developer ID signing, notarization, Gatekeeper verification, and a clean-Mac installation
check.
