# CodeReentry 0.3.0 Source Beta

CodeReentry is the new public name for DevHub. The narrower name describes the actual
job: return to the correct coding project, local AI session, and working context instead
of restarting from whichever tool happens to be open.

## Run this release

This remains a **source beta**. No binary is attached because the project does not yet
have a Developer ID signed and Apple-notarized public build. Do not install binaries
from unofficial mirrors.

Requirements: macOS 14 or newer and Xcode with Swift 6 support.

```bash
git clone --branch v0.3.0 https://github.com/roooooly/CodeReentry.git
cd CodeReentry
./scripts/run-source.sh
```

The command builds and verifies `CodeReentry.app` under the ignored `build/` directory.
The app does not scan projects or sessions until the user explicitly requests it.

## Name and data compatibility

The public product and repository names changed after a documented collision check. The
storage identity did not change: existing source-beta projects, settings, sessions,
plugin permissions, and Keychain references continue to use the original bundle ID and
`~/Library/Application Support/DevHub/` directory.

No user-data copy, move, or deletion is part of this release. See the complete
[naming and compatibility decision](https://github.com/roooooly/CodeReentry/blob/v0.3.0/docs/naming-decision.md).

## Product capabilities carried forward

- Bounded local-session discovery for Claude Code, Codex, ZCode, Kimi metadata, and
  OpenCode v1.18.19 metadata
- Exact-session resume where a verified tool interface supports it
- Project memory with session-summary provenance and stale-summary protection
- Explicit, user-initiated scans with no background history crawl
- Reproducible privacy and small/medium/20,000-session performance gates
- English and Simplified Chinese interfaces

## Verification boundary

The release is tagged only after the renamed main branch passes the one-command source
build, DevHubCore, synthetic fixture and performance-summary tests, English and
Simplified Chinese app tests, repository privacy audit, and re-entry-recorder tests.

Engineering tests are not presented as real-user evidence. The recovery hypothesis still
requires ten privacy-safe re-entry attempts, and public binary distribution remains
blocked on Developer ID signing, notarization, Gatekeeper verification, and a clean-Mac
installation check.
