# CodeReentry 0.7.0 Source Beta

CodeReentry 0.7.0 expands exact, local project re-entry to five more AI coding tools and
makes project cards reflect which configured tools are actually usable on the current
Mac. The release keeps the same explicit, read-only scan boundary: discovery is bounded
and metadata-first, while conversation text loads only after the developer opens one
session.

## Install the source beta

This remains a **source beta**. No binary is attached because the project does not yet
have a Developer ID signed and Apple-notarized public build. Do not install binaries
from unofficial mirrors.

Requirements: macOS 14 or newer and Xcode with Swift 6 support.

```bash
git clone --branch v0.7.0 https://github.com/roooooly/CodeReentry.git
cd CodeReentry
./scripts/run-source.sh --install
```

To evaluate the complete interface with disposable synthetic data and no access to local
projects or sessions, use `./scripts/run-source.sh --demo` instead.

## Recovery coverage added

- **OpenCode v1.18.19:** inspect bounded text and tool-call context from the selected
  SQLite session, then resume that exact session with `--session`.
- **Aider v0.86.2:** discover only the continuing history at an exact registered project
  root, inspect its newest bounded context, then restore it with
  `--restore-chat-history`.
- **Cline CLI v3.0.56:** discover root sessions from its read-only SQLite metadata store,
  with a bounded manifest fallback, and resume the complete ID with `--id`.
- **Goose v1.46.0:** inspect bounded user-visible text from the read-only shared session
  database and resume the complete ID with `session --resume --session-id`.
- **Pi v0.84.2:** discover project JSONL files from their headers, reconstruct bounded
  text from the active parent chain, and resume the exact file with `--session`.

Every reader rejects or skips symbolic links, applies format-specific file and content
budgets, and excludes private reasoning or tool traffic where the upstream format makes
that distinction. Exact format and command boundaries are recorded in the compatibility
notes under `docs/` and covered by sanitized fixtures.

Project cards now count only enabled tools whose configured executable or app is locally
available. CI also cross-compiles and verifies an x86_64 source bundle; this does not
replace the open Intel-hardware execution check.

## Evidence boundary

The fixtures and CI checks for these integrations are engineering evidence, not real-user
recovery trials. CodeReentry does not claim that the recovery hypothesis is validated.
The privacy-safe real-use protocol and its open evidence gate remain documented in
`docs/reentry-validation.md`.

The tag is created only after main passes the one-command source build, transactional
source-install tests, arm64 and x86_64 bundle verification, all DevHubCore tests,
synthetic performance checks, English and Simplified Chinese app tests, repository
privacy audit, and re-entry-recorder tests.

Public binary distribution remains blocked on Developer ID signing, notarization,
Gatekeeper verification, and a clean-Mac installation check.
