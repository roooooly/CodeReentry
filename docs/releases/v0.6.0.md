# CodeReentry 0.6.0 Source Beta

CodeReentry 0.6.0 closes the gap between a tested recovery feature and evidence from
real work. A developer can now start a local timer from session detail, resume the exact
session in the original tool, and record a structured result without exposing work
content. This release also makes source installation recoverable and preserves a manual
Terminal fallback when macOS blocks Automation.

## Install the source beta

This remains a **source beta**. No binary is attached because the project does not yet
have a Developer ID signed and Apple-notarized public build. Do not install binaries
from unofficial mirrors.

Requirements: macOS 14 or newer and Xcode with Swift 6 support.

```bash
git clone --branch v0.6.0 https://github.com/roooooly/CodeReentry.git
cd CodeReentry
./scripts/run-source.sh --install
open ~/Applications/CodeReentry.app
```

The installer stages and verifies a local build before replacing any prior source
installation. It refuses symbolic-link and foreign-bundle destinations and restores the
previous verified app if replacement fails. To inspect the isolated synthetic demo
without installing or reading local projects and sessions, run:

```bash
./scripts/run-source.sh --demo
```

## Measure recovery with real work

1. Open a registered project's Sessions tab and inspect the intended conversation.
2. Select **Measure This Recovery**. CodeReentry starts a local timer and opens the exact
   session in the original tool.
3. Confirm the project, session, and usable context, then return to **Recovery Evidence**
   and submit the structured result.

Completed records use an owner-only fixed CSV schema. It contains an anonymous derived
project slot, tool, coarse session age, durations, outcome, coarse repeated-background
reduction, cross-project flag, and failure category. It contains no source project
identifier, name, path, session ID, prompt, message, source content, or free-form note,
and CodeReentry has no upload path. Unfinished timers exist only in memory.

The dashboard reports correctness, median recovery time, relative improvement, coverage,
outcome targets, and failures. Development fixtures do not count as real evidence; the
published gate still requires ten real attempts across seven days, three anonymous
projects, two tools, and recent and older sessions.

## Recover from blocked Terminal Automation

If macOS refuses automatic Terminal control, CodeReentry preserves the owner-only launcher
and offers a one-time shell-quoted path command. The clipboard does not receive session
IDs, project memory, or environment values. Declining the fallback removes the launcher
and its managed memory file immediately; executed launchers remove themselves.

## Verification boundary

The tag is created only after main passes the one-command source build, transactional
installation tests, DevHubCore tests, synthetic performance gates, English and Simplified
Chinese app tests, repository privacy audit, and re-entry-recorder tests.

Engineering tests are not presented as real-user evidence. Public binary distribution
remains blocked on Developer ID signing, notarization, Gatekeeper verification, and a
clean-Mac installation check.
